# ETL com Python

Exercício do Santander Dev Week 2023. O script lê quatro clientes fictícios de `SDW2023.csv`, aplica 5% sobre o saldo inicial e imprime uma mensagem por cliente no terminal.

Com Python 3 e pip, execute na pasta do projeto:

```bash
python -m pip install pandas
python SDW2023.Filipe.Cardoso.py
```

Para testar outro cenário, altere os nomes e saldos no CSV. Com saldo inicial de 5000, o saldo final é 5250.
